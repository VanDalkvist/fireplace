# Костёр (fireplace)

Авторский инструмент **Вани Афанасова** для разговора о чувствах и желаниях: живой костёр, слова вокруг огня, процедурный звук и четыре фазы круга.

[Об авторе](https://vanya-arc.lovable.app). Практика проводилась в «Салоне присутствия» сообщества AI Mindset. Авторство инструмента, его сценария и механики — Ваня Афанасов; контекст сообщества не означает соавторства кода.

## Посмотреть демо

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Откройте **http://127.0.0.1:4343/?demo=1**.

Демо использует заранее подготовленный банк синтетических реплик (180+ вариантов), а не записи участников. Реплики динамически соответствуют выбранной фазе: начало, чувства, желания, завершение. Для генерации демо-фраз не нужны микрофон, ASR, LLM, API-ключи или сервер нейросетей. Звук включается действием пользователя; браузер может требовать клик для воспроизведения аудио.

Публичная витрина предназначена для демо. Не включайте голосовой ввод, если хотите только посмотреть демонстрацию. Демо не является воспроизведением реального разговора.

## Статическая сборка

```sh
npm run typecheck
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

Содержимое `dist/` можно разместить в любом подкаталоге статического сайта — пути сборки полностью относительные. Добавьте `?demo=1` к адресу страницы. Нейросетевая часть локального сетапа от этого не становится доступной на хостинге. Шрифт загружается с Google Fonts; сэмплы костра — из локальных файлов сборки.

## Локальный голосовой сетап

Живое распознавание — отдельный режим, требующий настроенных локальных сервисов и согласия участников на обработку речи. Vite обслуживает интерфейс и локальные прокси, но не устанавливает и не запускает модели.

По умолчанию в коде предусмотрены:

- GigaAM ASR: `http://127.0.0.1:9876`;
- Whisper ASR: `http://127.0.0.1:8085`;
- Sherpa, определение говорящего: `http://127.0.0.1:8086`;
- Ollama, обработка текста: `http://127.0.0.1:11434`;
- OpenRouter и Pi/Codex: через локальные Vite-прокси, с отдельно настроенной авторизацией.

Это адреса **машины, на которой открыт браузер**, а не серверов AI Mindset. Прокси существуют только в локальном dev-сервере, не в `dist/`. Для работы с голосом откройте страницу без параметра демо, настройте сервисы и выберите движки в пульте. API-ключи не добавляйте в URL или репозиторий; `OPENROUTER_API_KEY` задаётся в окружении либо в предусмотренном workspace-файле `.env` уровнем выше проекта.

## Что происходит с данными

- В голосовом режиме аудиосегменты передаются выбранному ASR и сервису определения говорящего. Аудио передаётся на настроенный сервис распознавания, даже если сервисы работают на том же ноутбуке.
- В режиме нейрообработки распознанный текст и недавний контекст передаются выбранной LLM. OpenRouter и Pi/Codex могут использовать внешних провайдеров. Браузерный Google STT также может отправлять аудио внешнему сервису.
- Режим «фраза» обходит нейросетевое сжатие текста, но не отменяет передачу аудио в ASR.
- Приложение сохраняет текстовые записи сессии, слова, связи и настройки в `localStorage` браузера. Они переживают перезагрузку; это не гарантированно эфемерная сессия. Данные также можно явно скопировать или экспортировать через аналитику.
- Диагностические логи ограничены строгим списком технических событий и разрешённых полей (размер блоба, статус, тип провайдера). Реплики, содержимое ответов ASR, произвольные сообщения и стеки ошибок в логи не попадают.
- Для удаления локального состояния используйте сброс круга или удаление данных сайта в браузере. Это не удаляет уже сделанные экспорты или данные на стороне внешних провайдеров.

Не размещайте выгрузки реальных кругов, записи участников и диагностические дампы в Git. Для живой встречи согласуйте обработку и хранение данных с участниками.
