# AGENTS.md · salon-presence

Локальный контракт проекта «Салон присутствия и чувств» (AIM Space).

## Миссия
Обеспечить чистую, модульную веб-среду для групповой практики присутствия, объединяя строгую дизайн-систему AI Mindset (S1), процедурный звук в D Dorian и детерминированный моушен Prompt Motion.

## Архитектурные правила проекта
1. **AP-019 (Лимиты размера):** Строгий лимит — не более 250 строк на файл (soft limit 150 строк). Никаких монолитных файлов.
2. **AP-010 / AP-020 (Изоляция слоев):**
   - Canvas-движок монтируется на заднем плане (`z-0`) и ничего не знает о React.
   - UI-оверлей (`z-10`) построен на shadcn/ui + Tailwind v4 с `pointer-events-none` на контейнере.
   - Обмен данными происходит только через типизированные порты и DTO (AP-026).
3. **Голосовой сценарий:** Основной режим — голосовое слушание (`VoiceListening`). В интерфейсе предусмотрен слот под алгоритм извлечения чувств, без принудительного ручного ввода.
4. **Селективное связывание реплик:** Связи между словами строятся по цепочке передачи голоса и эмоциональному резонансу, без создания сетки «все со всеми».
5. **Дизайн-система:** Все цвета, отступы и радиусы (2px) наследуются из `vendor/aim-upstream/` и маппятся в CSS-переменные темы.

## Команды
- `npm run dev` — локальный запуск Vite dev-сервера.
- `npm run test` — запуск детерминированных тестов Vitest.
- `npm run build` — проверка типов и сборка бандла.
