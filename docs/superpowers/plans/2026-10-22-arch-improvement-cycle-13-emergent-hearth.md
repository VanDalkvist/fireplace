# Architecture Improvement Plan - Cycle 13: Pure Contemplative Hearth & Dynamic Emergent Seating

- **Cycle:** 13
- **Goal:** Превратить салон присутствия в кристально чистое созерцательное пространство без интерфейсного мусора и жестких сеток:
  1. **Ликвидация UI-мусора с экрана:**
     - Удалить все чипы/тычки слов («тревожно», «тепло», «замедление», «устал», «тишины», «пас»).
     - Удалить кнопку «текст (enter)» и модальное окно `HearthInput`.
     - Удалить цифры и бейджи участников везде: на стульях, в индикаторах, в кнопках (`[01]`, `[02]`, `участник 04`).
     - Удалить симуляцию `space` (реплика из демо-скрипта).
  2. **Скрытая панель технических контролов (Collapsible Control Drawer / HUD):**
     - Основной экран — 100% чистое пространство костра.
     - Все технические кнопки (захват звука Zoom, сброс отпечатков голосов, выбор фазы, переключение STT, звук музыки) убираются в деликатную скрывающуюся панель (Drawer / Sheet / Collapsible HUD), открывающуюся по тонкой иконке настроек или хоткею `p` / `Escape`.
     - На основном экране внизу остаётся лишь тончайший индикатор дыхания/микрофона.
  3. **Динамический эмерджентный круг (Dynamic Emergent Seating — AP-054):**
     - Исходное состояние: **0 участников** (`participants: []`). Костёр горит в чистой тишине.
     - Когда участник начинает говорить и CAM++ распознает новый голос:
       - На овале вокруг костра органически рождается новая светящаяся точка (искра присутствия), занимающая свободный гармоничный угол.
       - Слова и чувства рождаются из этой точки и летят в костёр.
     - При повторной речи знакомого голоса: его существующая точка мягко пульсирует теплом, и слова рождаются из неё.
     - Кнопка «сброс голосов» в скрытой панели очищает отпечатки и обнуляет точки круга для новой практики.
  4. **Архитектурные инварианты (`arch-rules.md`):**
     - Лимит $\le 250$ строк на каждый файл (AP-019).
     - 0 циклических зависимостей (AP-025).
     - 0 типов `any`, строгий TypeScript (AP-029).
     - Детерминированные юнит-тесты Vitest для динамического круга (AP-028).
     - Двухконтурный гейт с независимым арх-ревьюером Gemini 3.8 High.

## Planned Slices

### Slice 1: Доменная модель динамического эмерджентного круга (`src/domain/session-fsm.ts`, `src/canvas/hearth-seats.ts`)
- **Scope:** `src/domain/session-fsm.ts`, `src/canvas/hearth-seats.ts`, `src/domain/types.ts`
- **AP Gates:** AP-010, AP-013, AP-014, AP-019
- **Tasks:**
  1. В `src/domain/types.ts`: сделать `participants: Participant[]` динамическим списком (начальный размер 0, без обязательного `number: number`).
  2. В `src/domain/session-fsm.ts`:
     - `createInitialState(initialCount = 0)` инициализирует сессию с пустым массивом `participants: []`.
     - Функция `ensureParticipant(state, speakerId)`: если участника с таким `speakerId` ещё нет, создает нового с органическим углом $\theta$ на овале (равномерно-гармоническое распределение, без наложения).
     - В `handleAddFeeling` / `handleAddDesire` / `setSpeaker`: автоматический вызов `ensureParticipant`.
     - Функция `resetParticipants(state)`: очистка всех участников круга.
  3. В `src/canvas/hearth-seats.ts`:
     - Отрисовка точек только для реально существующих участников (`participants`).
     - Полное удаление рендеринга текста номеров (`01`, `02`). Только чистое мягкое свечение искры присутствия, ореол тепла и пульсация при говорении.
  4. Юнит-тесты в `tests/dynamic-seats.test.ts` и обновление `tests/session-fsm.test.ts`.
